Browser extension (IDM jaisa)

Chrome / Edge / Brave mein har video par NexGrab button aata hai. Click karein, video seedha Windows app mein khul jati hai. Right-click menu se bhi.

  1. Windows app download karke kholein (extension us ke zip mein extension folder mein bhi hai).
  2. App mein Settings → Extension install karein dabayein, ya extension zip download karke extract karein.
  3. Browser ke Extensions page par Developer mode on karein, phir Load unpacked dabayein aur woh folder select karein.

Chrome Web Store YouTube downloaders ko allow nahi karta, is liye extension yahan se lagti hai. Woh sirf aap ke apne PC ki NexGrab app se baat karti hai, internet par kuch nahi bhejti.

Sawal jawab

Kya login ya account chahiye?

Nahi. Koi login nahi, koi account nahi, koi cookie banner nahi.

Kya aap meri history ya links save karte hain?

Nahi. Server koi database nahi rakhta aur links log nahi karta. File aap ke download karte hi server se delete ho jati hai; jo file koi na le woh 15 minute mein khud delete ho jati hai.

File kahan save hoti hai?

Browser ke normal Downloads folder mein. Phone par: File Manager → Download.

YouTube par "bot" wala error aaya?

YouTube kabhi kabhi servers ko rok deta hai. Thori der baad try karein - ya NexGrab Android / Windows app use karein, woh aap ke apne internet se chalti hai aur aisa kam hota hai.

APK install kaise karein?

APK download karein → kholein → "Install unknown apps" ki ijazat dein (sirf browser ke liye) → Install. Purani RSK Downloader app ke upar bhi update ho jati hai.

Windows "unknown publisher" kehta hai?

App signed nahi hai is liye. More info → Run anyway dabayein. Zip extract karke NexGrab.exe chalayein (tools folder saath rakhein).
